## 🔧 Технические изменения

### Рефакторинг архитектуры компонентов

#### `src/modules/chats-distribution/components/scenario-list/scenario-channel-cell/index.tsx`
- **Переработка размещения Popup**: Popup теперь оборачивает весь контент компонента
- **Централизация обработки событий**: `onClick` перенесен на обертку `<Box>` для улучшения UX
- **Адаптивное позиционирование**: Добавлены свойства `maxWidth={'auto'}` и `maxHeight={'auto'}`

```tsx
// БЫЛО:
<Popup placement={dropdownPlacement} visible={channelsModalScenario === scenario}>
    <Icon onClick={() => setChannelsModalScenario(scenario)} />
</Popup>

// СТАЛО:
<Popup placement={dropdownPlacement} visible={channelsModalScenario === scenario} 
       maxWidth={'auto'} maxHeight={'auto'}>
    <Box onClick={() => setChannelsModalScenario(scenario)} minHeight={20} minWidth={20}>
        <Icon hoverable />
    </Box>
</Popup>
```

#### `src/modules/chats-distribution/components/scenario/scenario-header-panel/index.tsx`
- **Логика определения заблокированных каналов**: Добавлена проверка принадлежности канала текущему сценарию

```tsx
// ДОБАВЛЕНО: Проверка принадлежности каналу текущему сценарию
const isInCurrentScenario = scenario.channels.some(c => c.id === channel.id);
const disabled = (disabledByEmployee || disabledByScenario) && !isInCurrentScenario;
```
